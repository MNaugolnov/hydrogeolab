ЗСО: линейный водозабор без естественного потока

line_0b_0f возвращает массив

Граница II пояса ЗСО для линейного ряда скважин в изолированном пласте без естественного потока.

Синтаксис

=line_0b_0f(q; t; l; k; m; n)

На ленте: Гидрогеология v.02›ЗСО›Калькулятор ЗСО

Формула

barT=Qtmnl2, R=barR·l, L=2R, d=2QtπmnL

Аргументы

#АргументОписаниеЕд. изм.
1qДебит водозабора Qм³/сут
2tРасчётное время t (время микробного/химического загрязнения)сут
3lДлина линейного ряда скважин lм
4kКоэффициент фильтрации пласта kм/сут
5mМощность водоносного пласта mм
6nАктивная пористость (недостаток насыщения / водоотдача) n—

Результат: массив из 6 значений, м.

  1. T̄ — безразмерное время
  2. R̄ — безразмерный радиус
  3. R — полудлина зоны, м
  4. d — полуширина зоны, м
  5. L — длина ЗСО, м
  6. 2d — ширина ЗСО, м

Пример использования

Ряд скважин длиной 500 м, суммарный дебит 2 000 м³/сут.

Функция возвращает массив: выделите ячейки под результат в строке, введите формулу и нажмите Ctrl+Shift+Enter. В Excel 365 результат «разольётся» по соседним ячейкам автоматически.

Попробуйте сами

Измените значения — результат пересчитывается по тому же алгоритму, что и в надстройке (JavaScript-версия функции).

Ограничения и возвращаемые ошибки

  • R̄ находится численно из интегрального уравнения (адаптивный метод Симпсона + бисекция).
  • Аргумент k в формуле не используется — он оставлен для единообразия с другими функциями.
  • #ЗНАЧ! — один из аргументов не является числом.
  • #ДЕЛ/0! — нулевой знаменатель (например, k = 0 или m = 0).
  • #ЧИСЛО! — недопустимые значения: отрицательное подкоренное выражение, логарифм от неположительного числа.
