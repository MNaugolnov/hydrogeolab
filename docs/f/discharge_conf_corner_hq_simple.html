Пласт-угол — одна граница H = const, другая непроницаемая: напорный пласт

discharge_conf_corner_hq_simple

Водоприток Q в выработку при заданном понижении S — пласт-угол — одна граница h = const, другая непроницаемая (H = const на расстоянии L₁, Q = 0 на расстоянии L₂), напорный пласт.

Синтаксис

=discharge_conf_corner_hq_simple(S_drawdown; k_filtr; m_power; r_dist; L1_near; L2_far)

На ленте: Гидрогеология v.02›Оценка водопритоков›Типовые схемы›Гидродинамический метод›Пласт-угол — одна граница H = const, другая непроницаемая›Напорный пласт

Формула

Q=2πkmSlnρ1ρ3rρ2

Попробуйте сами

Измените значения — результат пересчитывается по тому же алгоритму, что и в надстройке (JavaScript-версия функции).

Ограничения и возвращаемые ошибки

  • ρ₁ = 2L₁, ρ₂ = 2L₂, ρ₃ = √(ρ₁² + ρ₂²) — расстояния до скважин-отражений.
  • #ЗНАЧ! — один из аргументов не является числом.
  • #ДЕЛ/0! — нулевой знаменатель (например, k = 0 или m = 0).
  • #ЧИСЛО! — недопустимые значения: отрицательное подкоренное выражение, логарифм от неположительного числа.
