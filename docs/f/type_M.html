5Гидрохимия

type_M

Тип воды по минерализации возвращает текст

Название группы воды по минерализации (Петров Н.С., Потапов А.А., 1993).

Синтаксис

=type_M(value)

На ленте: Гидрогеология v.02›Гидрохимия›Классификации›Тип воды по минерализации

Формула

потаблицеклассификации

Классификация

Минерализация, г/лРезультат функции
≤ 0,2ультрапресные воды
0,2–1пресные воды
1–3слабосолоноватые воды
3–10солоноватые воды
10–35солёные воды
35–100слабые рассолы
> 100крепкие рассолы

Аргументы

#АргументОписаниеЕд. изм.
1valueМинерализация водыг/л

Результат: текст, например «пресные воды».

Пример использования

Проба с минерализацией 564 мг/л = 0,564 г/л.

B3fx=type_M(B1)

Попробуйте сами

Измените значения — результат пересчитывается по тому же алгоритму, что и в надстройке (JavaScript-версия функции).

Ограничения и возвращаемые ошибки

  • #ЗНАЧ! — один из аргументов не является числом.
  • #ДЕЛ/0! — нулевой знаменатель (например, k = 0 или m = 0).
  • #ЧИСЛО! — недопустимые значения: отрицательное подкоренное выражение, логарифм от неположительного числа.
