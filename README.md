# Cenozoic — сайт (статика для GitHub Pages)

Статический многостраничный сайт для `https://mnaugolov.github.io/hydrogeolab/`.

## Структура

```
index.html                 — главная (презентация, на основе Cenozoic Business Plan.docx)
product.html                — обзор всех расчётных модулей
parameters.html              — модуль «Расчётные параметры» + «Большой колодец»
reserves-inflow.html         — «Оценка запасов» и «Оценка водопритоков» (24 и 23 схемы)
zso-hydrochemistry.html      — «ЗСО» и «Гидрохимия»
tools.html                   — вспомогательные инструменты (агрегатор, координаты, карты, конвертер)
pricing.html                 — тарифы
company.html                 — о компании, дорожная карта, контакты

docs/                        — СПРАВОЧНИК (библиотека функций), собирается скриптами docsgen/
  index.html                 — каталог всех 90 функций и 6 окон с поиском
  f/<функция>.html           — страница каждой функции: синтаксис, формула, аргументы,
                               пример на листе Excel, «Попробуйте сами» (живой расчёт)
  tools/*.html               — окна-калькуляторы: ЗСО, Курлов, расстояние, номенклатура,
                               агрегатор, конвертер (интерактивные, кроме агрегатора)
  start.html                 — как пользоваться, разделители, массивы, ошибки
  examples.html              — сквозные примеры (водозабор, карьер, химанализ)
  glossary.html              — глоссарий параметров
docsgen/                     — генератор справочника (см. docsgen/README.md)

assets/
  css/style.css     — единая дизайн-система (тёмная главная в духе soilbox.app,
                       светлые страницы функционала в духе petroleumoffice.com)
  css/docs.css      — стили справочника
  js/main.js        — иконки, мобильное меню, плавное появление блоков
  js/hydro-lib.js   — JavaScript-версия всех функций надстройки (для живых примеров)
  js/docs.js        — поиск, калькуляторы и окна справочника
  img/logo.png      — логотип Cenozoic (logo1.png с прозрачным фоном)
  img/favicon-*.png, icon-*.png, apple-touch-icon.png — иконки сайта
  img/screens/      — реальные скриншоты из hydro_proto_v_0_2.xlsm и
                       Hydro_Ribbon_Concept_v2.pptx (лента, формы калькуляторов)

site.webmanifest   — иконки для «Добавить на экран»
.nojekyll          — отключает обработку Jekyll на GitHub Pages
```

## Как выложить на GitHub Pages

1. Скопируйте содержимое этой папки в корень репозитория `hydrogeolab`
   (или в ветку/папку, которую вы используете для Pages).
2. В настройках репозитория → **Settings → Pages** укажите источник:
   ветка `main`, папка `/ (root)` (или `/docs`, если положите файлы туда).
3. Через 1–2 минуты сайт будет доступен по адресу
   `https://mnaugolov.github.io/hydrogeolab/`.

Все ссылки в файлах — относительные (`index.html`, `assets/...`), поэтому
сайт одинаково работает и в корне домена, и в подпапке `/hydrogeolab/`.

## Что стоит поправить перед публикацией

- **Контактный email** — сейчас на странице `company.html` (раздел «Контакты»)
  стоит заглушка `hello@cenozoic-hydro.com`. Замените на реальный адрес
  (поиск по всем файлам: `hello@cenozoic-hydro.com`).
- **Цены и цифры** — взяты из `Cenozoic Business Plan.docx` как есть
  (например, диапазоны выручки и число пользователей — это план, а не факт).
- Разделы `zso.html`/`hydrochemistry` объединены в одну страницу
  `zso-hydrochemistry.html`; при желании их легко разнести на два файла —
  вёрстка модульная, шапка/подвал одинаковые на всех страницах.

## Логотип и иконки

`logo1.png` использован как логотип (с удалённым белым фоном —
`assets/img/logo.png`). Иконка вкладки браузера собрана из ракушки-аммонита
логотипа на тёмно-зелёном фоне (`favicon-*.png`, `icon-*.png`,
`apple-touch-icon.png`).

## Шрифты

Space Grotesk (заголовки) и Manrope (текст) подключены с Google Fonts.
Если сайт должен работать полностью офлайн/без внешних запросов — замените
`<link>` на Google Fonts в `<head>` каждой страницы на локальные файлы
шрифтов.
