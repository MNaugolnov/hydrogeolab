# docsgen — сборка справочника (папка `docs/`)

Справочник генерируется из кода надстройки, чтобы сайт не расходился с Excel.

1. Извлечь VBA-модули из надстройки (исходники **не** хранятся в репозитории —
   сайт публичный):
   ```
   python3 extract_vba.py путь/к/hydro_proto_v_0_2.xlsm vba_src
   python3 parse_sigs.py        # обновит sigs.json (подсказки Мастера аргументов)
   ```
2. Пересобрать JS-библиотеку функций `assets/js/hydro-lib.js`
   (reserves/inflow/atm — автотрансляция VBA→JS, остальное — ручной порт в `lib-handwritten.js`):
   ```
   python3 build-lib.py
   node test/verify.js          # сверка 51 формулы с независимой реализацией
   ```
3. Пересобрать страницы справочника:
   ```
   node build-docs.js
   ```
Тексты, примеры и формулы (TeX-подмножество, рендерится при сборке в `tex.js`)
редактируются в `docs-meta.js`. Добавили функцию в надстройку — добавьте её в
`MODULES` и `F` в `docs-meta.js`.
Не выкладывайте папку `vba_src/` в публичный репозиторий.
