Вспомогательные инструменты

Полезно не только гидрогеологам: расстояния, координаты, номенклатура карт, группировка данных и перевод единиц измерения — в одной группе на ленте.

Калькулятор расстояния

Форма расчёта расстояний между точками, плюс функция для вставки в формулу.

  • Диалоговая форма расчёта расстояний между точками
  • Функция Distance3D — вставляется прямо в ячейку
  • Поддержка 2D и 3D координат

Номенклатура карт

Номенклатура листов топографических карт по координатам.

  • Ввод координат в градусах или ГМС
  • Все масштабы: от 1:1 000 000 до 1:500
  • Готовый номенклатурный индекс листа для каждого масштаба

Конвертер размерностей

Перевод значений между единицами измерения без выхода из Excel.

  • Длина, площадь, объём, скорость, давление, коэф. фильтрации, расход и др.
  • Вызывается прямо с ленты «Гидрогеология»

Перевод координат

Градусы/минуты/секунды ⇄ десятичные градусы одной функцией.

  • DMStoDD — ГМС → десятичные градусы (знак результата равен знаку параметра «градусы»)
  • DDtoDMS — десятичные градусы → строка вида 55°45'07.92″
Данные → выводы

Агрегатор по столбцам

Группировка и агрегация выделенного диапазона: выберите диапазон и нажмите кнопку — инструмент сам предложит столбцы для группировки и агрегации.

Слои → интервалы

Группировка по «Скважина + Возраст» (MIN/MAX) сворачивает детальную литологическую колонку в геологически осмысленные интервалы: вместо построчных замеров «от–до» — итоговые границы каждого стратиграфического слоя по каждой скважине.

Результат

Скважины → характеристики по горизонтам

Группировка по «Водоносный горизонт» (SUM/AVG) агрегирует характеристики по каждому горизонту сразу для всех скважин участка. Инструмент честно предупреждает, какие столбцы не попадут в результат — так исключается риск потерять данные незаметно.
